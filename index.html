Online Examination System

A web platform that replaces pen-and-paper exams: students register, log in, and take a timed multiple-choice test; the server grades it the moment it's submitted, and admins can see every attempt from one dashboard.

Node.js Express EJS MySQL / JSON Sessions
  • Separate Admin and Student logins, with session-based authentication
  • 10-question Data Structures test bank, auto-graded on submission
  • Countdown timer that auto-submits the exam when time runs out
  • Admin dashboard listing every attempt, score, and timestamp
